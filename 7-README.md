# THE SIGNAL ROOM
An original, playable, illustrated stealth game inspired by the visual language of a square-format comic-book conspiracy game trailer. All art is drawn in Canvas code; no footage, sprites, models, music, or other assets from the reference are included.

Open `index.html` in a browser. No build system, account, API, or paid dependency. The optional Google font has local fallbacks; the game works offline.

Move with WASD/arrow keys; Shift to sprint; E/Space to pick up a nearby file; R restarts; M toggles sound. On touch devices use the directional pad and tap a nearby file. Collect the three files and reach the right-side red fire exit without staying in the guard's searchlight. The green cabinet blocks his view.

This is a concise 2D stealth vignette, not the reference game's footage or a recreation of its entire sequence. Reference: https://x.com/georgjutvall/status/2103161227585147147 (quoted by https://x.com/aelthemplaer/status/2103235980983783436).
